TESTING DECISION FRAMEWORK

Use ASK when:
- Need to understand edge cases
- Want to explore test coverage gaps
- Unfamiliar with code being tested
- Need to understand existing test patterns
- Want suggestions for test scenarios

Use EDIT when:
- Know exactly what test case to write
- Adding single specific test
- Modifying existing test
- Test scenario straightforward

Use AGENT when:
- Need complete test suite for module
- Want comprehensive coverage (happy path + edge cases)
- Testing multiple related functions
- Need both unit and integration tests

Combine modes:
- ASK for scenarios → EDIT/AGENT to generate
- AGENT for initial suite → EDIT to refine
- ASK for missing coverage → EDIT to add

---

PRO TESTING TIPS

Planning:
- Use ASK to explore what needs testing
- Ask about edge cases you might miss
- Understand test framework patterns first
- Check existing tests for style consistency

Generation:
- EDIT for single tests - focused and quick
- AGENT for suites - comprehensive coverage
- Specify test framework (Vitest, Jest) in prompts
- Request descriptive test names for clarity

Validation:
- Run tests immediately: yarn test:unit
- Check coverage - ensure critical paths tested
- Verify assertions - are they meaningful?
- Test both success and failure paths
