COPILOT CHAT MODE SELECTION TRAINING
=====================================

MODE SELECTION GUIDE:
- ASK: Unclear goals, exploration, understanding existing code
- EDIT: Small local edits (one function/file)
- EDIT + ASK: Guided iterative improvements
- ASK → EDIT → VALIDATE: Higher-risk multi-step changes
- AGENT: Multi-file changes, complex features, refactoring

DECISION TREE:
Task clear? → NO → ASK mode
           → YES → Multiple files? → YES → AGENT mode
                                  → NO → Risky/unfamiliar? → YES → ASK → EDIT
                                                           → NO → EDIT mode
