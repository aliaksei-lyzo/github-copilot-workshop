# Awesome Copilot Integration

Learn how to enhance your project with community resources from [awesome-copilot](https://github.com/github/awesome-copilot).

---

## 🤖 What is Awesome Copilot?

Awesome Copilot is a community repository with reusable:
- **Prompts** - Ready-to-use templates for specific tasks
- **Instructions** - Coding standards and best practices
- **Chat Modes** - Specialized AI personas
- **Collections** - Curated sets of related resources

---

## 🎯 Your Task

Explore awesome-copilot and add useful resources to this project.

---

### Task #1: Add a Testing Prompt from Awesome Copilot

**Goal:** Install a reusable test generation prompt to help create better tests.

**What to do:**
1. Browse [awesome-copilot prompts](https://github.com/github/awesome-copilot/tree/main/prompts)
2. Find a testing-related prompt (e.g., unit tests, integration tests)
3. Install it to `.github/copilot-prompts/` in this project
4. Test it by generating a test for a component

**Questions:**
- Which prompt did you choose and why?
- How does it compare to writing tests manually?
- Did you need to customize it for this project?

---

### Task #2: Create Custom Instructions for This Project

**Goal:** Write custom instructions that help Copilot understand this project better.

**What to do:**
1. Look at examples in [awesome-copilot instructions](https://github.com/github/awesome-copilot/tree/main/instructions)
2. Create `.github/copilot-instructions.md` for this project
3. Include:
   - Tech stack (React, TypeScript, Material-UI, Express)
   - Patterns used (Formik forms, styled components with PREFIX)
   - Naming conventions (data-test attributes, validation patterns)
   - File organization

**Questions:**
- What patterns did you document?
- How specific should instructions be?
- Did Copilot generate better code after adding instructions?

---

### Task #3: Try the README Generator Prompt

**Goal:** Use awesome-copilot's README generator to improve project docs.

**What to do:**
1. Install the [README generator prompt](https://github.com/github/awesome-copilot/blob/main/prompts/readme-blueprint-generator.prompt.md)
2. Run it to generate a new README section
3. Compare with existing `PROJECT_README.md`
4. Add any missing useful sections

**Questions:**
- What new sections did it suggest?
- Is the generated content accurate?
- What would you keep vs. rewrite?

---

### Task #4: Suggest Resources with the Discovery Prompt

**Goal:** Let Copilot suggest relevant awesome-copilot resources for this project.

**What to do:**
1. Install the [suggest prompts](https://github.com/github/awesome-copilot/blob/main/prompts/suggest-awesome-github-copilot-prompts.prompt.md) prompt
2. Run it to discover relevant resources
3. Review suggestions and install 2-3 useful ones
4. Test them on real project tasks

**Questions:**
- What resources did Copilot suggest?
- Were suggestions relevant to this project?
- Which ones are most useful for your workflow?

## 💡 Tips for Success

**Finding Resources:**
- Search by tech stack (React, TypeScript, Node.js)
- Look for patterns that match your project
- Check collections for grouped resources

**Installing:**
- Copy `.prompt.md` files to `.github/copilot-prompts/`
- Copy `.instructions.md` to `.github/copilot-instructions.md`
- Test with `#` in Copilot Chat to see your prompts

**Customizing:**
- Adapt examples to your project structure
- Keep instructions specific and actionable
- Test and refine based on results
