Project Setup Guide

Fork, clone, and configure the workshop project before starting the exercises.

📋
Prerequisites
  • Node.js: v18, v20, or v22
  • Yarn: v1.22 or higher
  • GitHub Copilot: Active subscription and IDE extension installed
1

Fork & Clone the Repository

Goal: Get your own copy of the workshop project.

Fork the repository to your own GitHub account
Clone to your local machine:
git clone https://github.com/YOUR_USERNAME/github-copilot-workshop.git
cd github-copilot-workshop
2

Install Dependencies

Goal: Install all project dependencies and seed the database.

# Install dependencies
yarn install

# Seed the database
yarn db:seed:dev
3

Verify Setup

Goal: Confirm everything is working correctly.

Start the application:
yarn start
  • Verify the app opens at http://localhost:3000
  • Check that the UI loads without errors
  • Confirm you can see the login page
Run tests:
yarn test
  • Cypress Test Runner should open
  • Run a simple test (e.g., from cypress/tests/ui/)
  • Verify tests pass successfully
Check TypeScript:
yarn types
  • TypeScript compilation should complete without errors
Verify the UI:
  • Try logging in with a test user (check data/database.json for credentials)
  • Navigate through different pages
  • Confirm no console errors in browser DevTools
Success Criteria
All commands run without errors, UI is accessible, and at least one Cypress test passes.

Available Scripts

🚀
Running the Application
Command Description
yarn start Start development server (React + API)
yarn dev Development mode with hot reload
yarn dev:coverage Start with coverage enabled
yarn start:empty Start with empty database
yarn build Build for production
🧪
Testing
Command Description
yarn test Open Cypress UI
yarn test:headless Run headless tests
yarn test:api Run API tests
yarn test:unit Run unit tests
🛠️
Development Tools
Command Description
yarn lint Check code style
yarn prettier Format code
yarn types TypeScript type checking
yarn db:seed Regenerate seed data
💡
Workshop Tip

Configure Copilot to exclude workshop files from context for optimal performance. The WORKSHOP/ and WORKSHOP_V2/ folders contain exercises that shouldn't influence Copilot's suggestions for the main codebase.

✅ Setup Checklist

  • Forked repository to own GitHub account
  • Cloned repository locally
  • Installed dependencies with yarn
  • Seeded the database
  • App runs at localhost:3000
  • Cypress tests pass
  • TypeScript compiles without errors
  • Can log in with test user
