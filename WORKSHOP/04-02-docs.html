Copilot Documentation Generation

Generate, update, and visualize documentation with AI assistance.

🎯 Learning Objectives

  • Keep documentation in sync with code
  • Generate diagrams using Mermaid.js
  • Create architecture diagrams with Draw.io
  • Automate documentation updates
📚
Copilot isn't just for code!

It can generate, update, and visualize documentation:

  • Keeping docs in sync with code
  • Generating diagrams (Mermaid, Draw.io)
  • Automating documentation updates
1

Update Project README

Goal: Update the main project documentation to reflect recent changes.

📄
Context: The PROJECT_README.md file might be outdated.
Open PROJECT_README.md
Ask Copilot to update based on actual code:
▶ 💬 Prompt 
Read the file `backend/app.ts` and `backend/auth.ts`. Update the 'Authentication' section in `PROJECT_README.md` to accurately reflect the current implementation.
Expected Result
Copilot suggests changes to the README based on the actual code
2

Generate Mermaid Diagrams

Goal: Visualize the database schema or API structure using Mermaid.js.

📄
Context: backend/graphql/schema.graphql defines the data model.
Create a new file docs/schema_diagram.md (create the docs folder if needed)
Ask Copilot to generate the diagram:
▶ 💬 Prompt 
Generate a Mermaid class diagram representing the GraphQL schema defined in `backend/graphql/schema.graphql`.
Preview the markdown to see the diagram
Expected Result
A valid Mermaid code block that renders a class diagram of Users, BankAccounts, Transactions, etc.
3

Create Draw.io Architecture Diagram

Goal: Create a high-level architecture diagram using Draw.io XML.

Create a new file docs/architecture.drawio
Ask Copilot to generate the XML:
▶ 💬 Prompt 
Generate the XML content for a Draw.io diagram showing the high-level architecture: React Frontend -> Express Backend -> JSON Database. Include the Authentication service.
Paste the generated XML into docs/architecture.drawio
Open the file (requires Draw.io extension) to view the diagram
Expected Result
XML content that renders as a diagram in Draw.io
4

Automate Doc Updates (Custom Instructions)

Goal: Ensure documentation is updated whenever code changes.

Open your Copilot Custom Instructions (or just give a session instruction)
Add the following instruction:
▶ 💬 Session Instruction 
For the rest of this session, whenever I modify a backend route, please remind me to update `PROJECT_README.md` and suggest the specific text changes.
Modify backend/transaction-routes.ts (e.g., add a comment or small change)
Observe Copilot's response
Expected Result
Copilot includes a reminder or a suggested doc update in its response

🔑 Key Learnings

  • Documentation should live with the code
  • Visuals (Mermaid) are easy to generate from code
  • You can condition Copilot to act as a "Documentation Guardian"

✅ Completion Checklist

  • Updated README based on actual code
  • Generated Mermaid class diagram
  • Created Draw.io architecture diagram
  • Set up automated doc update reminders
