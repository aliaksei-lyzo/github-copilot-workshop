Playwright MCP Server

Generate, run, and debug Playwright tests with AI assistance.

🎯 Learning Objectives

  • Install and configure Playwright MCP server
  • Create structured prompts for test generation
  • Generate tests from user scenarios
  • Run and debug tests using MCP tools
🎭
What is Playwright MCP?

The Playwright MCP server allows Copilot to interact with Playwright to:

  • Generate tests from user scenarios
  • Run tests and report results
  • Debug failing tests
  • Manage Playwright browsers
1

Installation and Setup

Goal: Install Playwright and the Playwright MCP server.

Step 1: Install Playwright

Run the following command in your terminal:
yarn create playwright
💡
Installation Options:
  • Select tests as the tests directory (or e2e if you prefer)
  • Install browsers when prompted

Step 2: Install Playwright MCP Server

Open Command Palette (Cmd+Shift+P)
Type "MCP: Add Server"
Search for "Playwright" (or "mcp-playwright")
Install it

Step 3: Verify Installation

▶ 💬 Verification Prompt 
Can you list the available Playwright tools?
Expected Result
Copilot lists available Playwright MCP tools like running tests, creating tests, etc.
2

Generate Test Plan (Prompt Engineering)

Goal: Create a reusable prompt for generating high-quality Playwright tests.

📝
Why? We want to ensure Copilot follows a strict process when generating tests: analyze → plan → generate → verify.
Create a file prompts/generate_test.prompt.md (create folder if needed)
Paste the following content:
▶ 📄 Prompt File Content 
- You are a playwright test generator.
- You are given a scenario and you need to generate a playwright test
- DO NOT generate test code based on the scenario alone.
- DO run steps one by one using the tools provided by the Playwright MCP
- Only after all steps are completed, emit a Playwright TypeScript test
- Save generated test file in the tests directory
- Execute the test file and iterate until the test passes
💡
Usage: When you want to generate a test, you can reference this prompt or paste it into the chat context.
Expected Result
A reusable prompt file that ensures systematic test generation
3

Generate Specific Test (Login)

Goal: Generate a test for the login functionality of this application.

📄
Context:
  • The app has a login page at /signin
  • Default user: Katharina_Bernier (check data/database.json for valid usernames)
  • Password: s3cret
Ask Copilot using the prompt from Task 2:
▶ 💬 Prompt 
Using the instructions in `prompts/generate_test.prompt.md`, generate a Playwright test for the login flow.

Scenario:
1. Navigate to the sign-in page.
2. Enter valid credentials (username: 'Katharina_Bernier', password: 's3cret').
3. Click the sign-in button.
4. Verify that the user is redirected to the home page.
Expected Result
  • Copilot uses MCP tools to create the file tests/login.spec.ts
  • It runs the test
  • If it fails, it attempts to fix it
4

Run and Debug Tests

Goal: Use MCP to run tests and debug issues.

Run All Tests

▶ 💬 Run All Tests Prompt 
Run all Playwright tests.

Debug a Specific Test

If a test fails, ask Copilot to debug it:

▶ 💬 Debug Prompt 
Debug the test `tests/login.spec.ts` and explain why it failed.
Expected Result
  • Copilot runs the tests using the MCP tool
  • It provides a summary of the results
  • For failures, it explains the issue and suggests fixes

🔑 Key Learnings

  • MCP allows Copilot to execute tests, not just write them
  • Structured prompts (like Task 2) improve the reliability of agentic workflows
  • You can iterate on tests (Write → Run → Fix) entirely within the chat

✅ Completion Checklist

  • Installed Playwright and Playwright MCP server
  • Created reusable test generation prompt
  • Generated login test using MCP tools
  • Ran and debugged tests using MCP
