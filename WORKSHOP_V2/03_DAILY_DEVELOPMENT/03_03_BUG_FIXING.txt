GITHUB COPILOT BUG FIXING
==========================

BUG FIXING WORKFLOW:
1. ASK Mode - Investigate and understand root cause
2. EDIT Mode - Apply fix to specific files
3. AGENT Mode - Validate fix doesn't break anything (optional)

DEBUGGING DECISION FRAMEWORK

Use ASK when:
- Don't know where bug is
- Bug could be in multiple places
- Need to understand code flow
- Want error traces explained
- Need architecture context

Use EDIT when:
- Identified exact location
- Fix is in single file
- Know what needs to change
- Simple bug fix

Use AGENT when:
- Bug affects multiple files
- Need to refactor to fix properly
- Want comprehensive test coverage
- Validation requires checking many scenarios

Combine modes:
- ASK to investigate → EDIT to fix
- ASK to understand → AGENT to fix + validate
- EDIT to fix → ASK to verify approach
- EDIT to fix → AGENT to add tests

---

PRO DEBUGGING TIPS

Investigation:
- Start with ASK if root cause unclear
- Provide error messages to Copilot
- Ask about data flow to trace bug
- Request similar bugs to learn patterns

Fixing:
- Use EDIT for surgical fixes in known locations
- Select relevant code before asking
- Review generated fix before applying
- Prefer small, focused changes

Validation:
- Ask for test cases covering bug scenario
- Use AGENT to add regression tests
- Verify edge cases
- Check related functionality hasn't broken
