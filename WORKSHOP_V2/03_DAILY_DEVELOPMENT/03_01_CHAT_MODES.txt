CHAT MODES IN GITHUB COPILOT
=============================

THREE MODES:
- Ask Mode (@workspace) - Questions and exploration
- Edit Mode - Code changes with preview
- Agent Mode - Multi-step autonomous tasks

---

TASK 0.1: COMMENT AUTOCOMPLETE - GENERATE VALIDATION FUNCTION

Coding Task: Create a reusable validation function for transaction amounts.

File: src/components/TransactionCreateStepOne.tsx
1. Navigate to line 50 (below existing validation)
2. Type a comment describing validation function
3. Wait for Copilot suggestion
4. Press Tab to accept

Expected: Complete function implementation from comment
Hint: Try "// Function to validate transaction amount is between min and max values"
