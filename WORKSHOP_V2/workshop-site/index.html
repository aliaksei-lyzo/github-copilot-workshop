💡 How to Use This Workshop

  • Try prompts yourself first! Each task has hidden hints and suggested prompts - try to solve it on your own before revealing them.
  • Work through exercises in order - each module builds on concepts from previous ones.
  • Experiment and iterate - AI responses vary, so don't expect identical results. Learn from the differences!
  • Check your understanding - answer the reflection questions at the end of each task.
  • Use the project codebase - exercises reference files in the Real World App project.
💡
Pro Tip: Keep VS Code open alongside this workshop. You'll be switching between reading tasks and trying them in your editor.
