GitHub Copilot Basic Usage

Learn the fundamental ways to interact with Copilot: code suggestions, inline chat, and the three chat modes.

🎯 Learning Objectives

  • Use code suggestions with inline comments
  • Work with inline chat for quick edits
  • Leverage Copilot Chat in Ask mode for understanding code
  • Use Copilot Chat in Edit mode for code modifications
  • Apply Copilot Chat in Agent mode for complex multi-file tasks
1

Code Suggestions with Inline Comments

Task: Create transaction filter utility using comment-driven development.

src/utils/transactionFilters.ts (new file)

Create new file src/utils/transactionFilters.ts
Use inline comments to generate utility functions
Let Copilot autocomplete implementation
▶ 💡 Comments to write 
import { Transaction, TransactionStatus } from "../models/transaction";

// Function to filter transactions by amount range
// Parameters: transactions array, minAmount (optional), maxAmount (optional)
// Returns: filtered array of transactions

// Function to filter transactions by date range
// Parameters: transactions array, startDate (optional), endDate (optional)
// Returns: filtered array of transactions within the date range

// Function to filter transactions by status
// Parameters: transactions array, status
// Returns: filtered array of transactions matching the status

// Function to combine multiple filters
// Parameters: transactions array, filters object with optional amount, date, and status filters
// Returns: filtered array of transactions matching all provided filters
Expected Result
Complete function implementations with TypeScript typing, handles optional parameters
▶ 🔮 Hint
Write descriptive comments, wait for suggestions, press Tab to accept
✅
Verification: Run yarn types (check no errors), manually test with sample data

Inline Chat

Task: Add error handling to API routes using inline chat.

backend/transaction-routes.ts

Open backend/transaction-routes.ts
Find POST /transactions route handler
Select route handler code block
Open Inline Chat: Cmd+I (Mac) or Ctrl+I (Windows/Linux)
Enter your prompt and review changes
▶ 💬 Suggested Prompt 
Add comprehensive error handling with appropriate HTTP status codes and error logging
Expected Result
Try-catch blocks, proper error responses (400, 404, 500), error logging, preserved functionality
▶ 🔮 Hint
Select code first, use Cmd+I for quick focused edits

Copilot Chat - Ask Mode

Task: Understand transaction flow using Ask mode.

backend/transaction-routes.ts

Open backend/transaction-routes.ts
Find POST route for creating transactions
Select entire route handler code
Open Copilot Chat panel
Ask your question about the code
▶ 💬 Suggested Prompt 
@workspace /explain How does the transaction creation flow work from API request to database storage? Include validation, authentication, and error handling.
Expected Result
Clear explanation of end-to-end flow, mentions validation/auth/database, references relevant files
▶ 🔮 Hint
Use @workspace for codebase-wide understanding, Ask mode doesn't modify code
Follow-up questions to try
  • "What happens if a transaction fails validation?"
  • "How is the user authenticated in this route?"
  • "Where is the transaction data persisted?"

src/components/BankAccountForm.tsx

Open src/components/BankAccountForm.tsx

Copilot Chat - Agent Mode

Task: Implement transaction search feature across multiple files.

Files: Multiple (frontend and backend)

Open Copilot Chat
Use @workspace agent
Describe the complete search feature requirements
▶ 💬 Suggested Prompt 
@workspace Implement a transaction search feature:

Backend (backend/transaction-routes.ts):
- Add GET /transactions/search endpoint
- Support query parameter: searchTerm (searches in description field)
- Return matching transactions with pagination
- Use existing authentication and validation patterns

Frontend:
- Create SearchBar component in src/components/SearchBar.tsx with Material-UI TextField
- Add search input with debouncing (300ms) to avoid excessive API calls
- Display search results using existing TransactionList component
- Add to TransactionsTabs or appropriate container

Follow existing code patterns and TypeScript conventions in the project.
Expected Result
Multi-file changes, new backend route with auth/validation, React component with TypeScript, search in UI, debouncing, follows project conventions
▶ 🔮 Hint
Use @workspace for complex tasks, let agent plan and coordinate changes, observe how it breaks down tasks
✅
Verification: Run yarn types, yarn start, test search functionality in UI
What to observe
  • How agent breaks down task into steps
  • File organization and imports
  • Integration with existing code
  • Error handling and edge cases

✨ Best Practices Learned

  • Code Suggestions: Write clear, descriptive comments. Let Copilot complete implementations. Review and refine suggestions.
  • Inline Chat: Quick edits without switching context. Select relevant code before prompting. Use for focused, single-file changes.
  • Ask Mode: Understand unfamiliar code. Learn project patterns. Get explanations without modifications.
  • Edit Mode: Direct code modifications. Specific feature requests. Incremental improvements.
  • Agent Mode: Complex, multi-file tasks. Coordinated changes across layers. Maintains project consistency.
💡
Tips for Success:
  • Be Specific: More detailed prompt = better output
  • Provide Context: Use @workspace, #file, or #selection when needed
  • Iterate: Don't expect perfection first try - refine and iterate
  • Review Carefully: Always review generated code before accepting
  • Follow Patterns: Reference existing code patterns in prompts
  • Test Early: Run yarn types and tests frequently

✅ Completion Checklist

  • Tested new features in running application
  • Understand when to use each Copilot mode
