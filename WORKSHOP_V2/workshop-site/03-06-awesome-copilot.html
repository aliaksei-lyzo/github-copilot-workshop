Awesome Copilot Integration

Discover and use community-curated prompts, instructions, and resources.

🎯 Learning Objectives

  • Explore the awesome-copilot repository
  • Install and test community prompts
  • Create custom instructions for your project
  • Discover resources that improve your workflow
🌟
What is Awesome Copilot?

Community repository with reusable:

  • Prompts - Ready-to-use templates for specific tasks
  • Instructions - Coding standards and best practices
  • Chat Modes - Specialized AI personas
  • Collections - Curated sets of related resources

🔗 github.com/github/awesome-copilot

1

Add Testing Prompt from Awesome Copilot

Task: Install reusable test generation prompt to help create better tests.

Browse awesome-copilot prompts: prompts directory
Find testing-related prompt (unit tests, integration tests)
Install to .github/copilot-prompts/ in this project
Test by generating a test for a component
Questions to Answer
  • Which prompt did you choose and why?
  • How does it compare to writing tests manually?
  • Did you need to customize it for this project?
Expected Result
Installed testing prompt that generates quality tests matching project patterns
▶ 🔮 Hint
Look for React/TypeScript testing prompts, copy .prompt.md file, test with # in Chat
2

Create Custom Instructions for This Project

Task: Write custom instructions that help Copilot understand this project better.

Look at examples: instructions directory
Create .github/copilot-instructions.md for this project
Include project-specific details:
  • Tech stack (React, TypeScript, Material-UI, Express)
  • Patterns (Formik forms, styled components with PREFIX)
  • Naming conventions (data-test attributes, validation patterns)
  • File organization
Questions to Answer
  • What patterns did you document?
  • How specific should instructions be?
  • Did Copilot generate better code after adding instructions?
Expected Result
Custom instructions file that improves Copilot's code generation for this project
▶ 🔮 Hint
Document project-specific patterns, be specific about conventions, reference key files
3

Try README Generator Prompt

Task: Use awesome-copilot's README generator to improve project docs.

Install README generator: readme-blueprint-generator.prompt.md
Run it to generate new README section
Compare with existing PROJECT_README.md
Add any missing useful sections
Questions to Answer
  • What new sections did it suggest?
  • Is generated content accurate?
  • What would you keep vs. rewrite?
Expected Result
Enhanced project documentation with useful sections
▶ 🔮 Hint
Copy prompt file, invoke with #, review generated content before adding to docs
4

Discover Resources with Suggestion Prompt

Task: Let Copilot suggest relevant awesome-copilot resources for this project.

Install suggest prompts: suggest-awesome-github-copilot-prompts.prompt.md
Run it to discover relevant resources
Review suggestions and install 2-3 useful ones
Test them on real project tasks
Questions to Answer
  • What resources did Copilot suggest?
  • Were suggestions relevant to this project?
  • Which ones are most useful for your workflow?
Expected Result
2-3 additional useful prompts/resources installed and tested
▶ 🔮 Hint
Run discovery prompt, evaluate relevance, install most useful ones, test on actual tasks

💡 Tips for Success

🔍
Finding Resources:
  • Search by tech stack (React, TypeScript, Node.js)
  • Look for patterns matching your project
  • Check collections for grouped resources
📥
Installing:
  • Copy .prompt.md files to .github/copilot-prompts/
  • Copy .instructions.md to .github/copilot-instructions.md
  • Test with # in Copilot Chat to see your prompts
🔧
Customizing:
  • Adapt examples to your project structure
  • Keep instructions specific and actionable
  • Test and refine based on results
🏆
Bonus Challenges:
  1. Create Form Prompt: Make reusable prompt for generating Material-UI + Formik forms based on project pattern
  2. Share Back: Contribute your custom prompt to awesome-copilot if useful for others
  3. Build Collection: Create collection of prompts/instructions for React payment apps

✅ Success Metrics

Successfully integrated awesome-copilot when:

  • At least 2-3 prompts installed and working
  • Custom instructions improve code generation
  • Resources save time on repetitive tasks
  • Generated code matches project patterns
