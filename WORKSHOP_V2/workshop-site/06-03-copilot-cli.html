GitHub Copilot CLI

AI-powered coding assistance directly in your terminal.

🎯 Learning Objectives

  • Install and authenticate Copilot CLI
  • Use basic commands (/help, /model, /exit)
  • Ask codebase questions from the terminal
  • Perform coding tasks without leaving CLI
  • Integrate with GitHub operations
  • Extend functionality with MCP servers
💻
What is Copilot CLI?

GitHub Copilot CLI brings AI coding assistance to your terminal. It can:

  • Answer questions about your codebase
  • Generate and modify code
  • Create and review Pull Requests
  • Execute terminal commands
  • Extend capabilities via MCP servers
📋
Prerequisites
  • Node.js v22+ - Required for installation
  • GitHub Copilot subscription - Active license
  • GitHub CLI (optional) - For GitHub integration
1

Install Copilot CLI

Goal: Install the GitHub Copilot CLI tool globally.

Verify Node.js version:
node --version  # Should be v22.0.0 or higher
Install Copilot CLI globally:
npm install -g @githubnext/github-copilot-cli
Verification
copilot --version
2

Authenticate with GitHub

Goal: Authenticate the CLI with your GitHub account.

Start Copilot CLI:
copilot
Use the login command:
/login
Follow the browser authentication flow
💡
Authentication persists across sessions. You only need to login once.
3

Explore Basic Commands

Goal: Learn the essential CLI commands.

Command Description
/help Show available commands
/model List or change AI model
/login Authenticate with GitHub
/feedback Send feedback to GitHub
/exit Exit the CLI
Try listing available models:
/model
🤖
Available Models
  • Claude Sonnet 4.5
  • Claude Sonnet 4
  • GPT-5

7

Extend with MCP Servers

Goal: Add MCP servers to extend Copilot CLI capabilities.

🔌
MCP in CLI

Copilot CLI supports the same Model Context Protocol (MCP) servers as VS Code. This means you can add:

  • Context7 for documentation lookup
  • Playwright for browser automation
  • Custom MCP servers
▶ 📄 MCP Configuration Example

Create ~/.config/github-copilot-cli/mcp.json:

{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@context7/mcp"]
    }
  }
}
⚡
Efficient CLI Workflow
  • Stay in project directory - CLI automatically uses repo context
  • Use specific file paths - "in backend/auth.ts" helps focus
  • Chain tasks - "create a function, then add tests for it"
  • Review before confirming - always check diffs

🔑 Key Points

  • Alternative to VS Code - full Copilot power in terminal
  • Same models - Claude, GPT-4 available
  • File operations - can read, create, and modify files
  • GitHub integration - PRs, issues, reviews
  • MCP extensible - same protocol as VS Code
  • Context-aware - understands your project structure
