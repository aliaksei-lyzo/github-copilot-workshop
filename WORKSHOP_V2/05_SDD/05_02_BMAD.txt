BMAD METHOD: AI-DRIVEN AGILE DEVELOPMENT
=========================================

WHAT IS BMAD METHOD?

BMAD (Build More, Architect Dreams) is an AI-driven agile development framework
that uses specialized AI agents and guided workflows. Unlike generic AI coding
assistants, BMAD provides:

- 19 specialized agents (PM, Architect, Developer, UX Designer, etc.)
- 50+ guided workflows across 4 development phases
- Scale-adaptive intelligence (bug fixes to enterprise platforms)
- Complete development lifecycle support

Key Philosophy:
- Structured agile workflows with AI amplification
- Specialized expertise through domain-specific agents
- Phase-based methodology: Analysis → Planning → Solutioning → Implementation
- Fresh chats for each workflow to avoid hallucinations

---

PREREQUISITES

Before starting:
1. Node.js 18+ installed
2. VS Code with GitHub Copilot extension
3. Git installed
4. This workshop project cloned

---

TASK 1: INSTALL BMAD METHOD

Goal: Install the BMAD Method CLI and set up your project.

Steps:

1. Open terminal in VS Code (Ctrl+` or Cmd+`)

2. Navigate to project root:
   ```bash
   cd /path/to/github-copilot-workshop
   ```

3. Install BMAD Method (v6 Alpha - current recommended version):
   ```bash
   npx bmad-method@alpha install
   ```

4. During installation, you'll be prompted for:
   - Installation directory (default: current directory)
   - Modules to install (select BMad Method - BMM)
   - IDE selection (select GitHub Copilot)
   - VS Code settings configuration (use recommended defaults)

5. Verify installation - check for new folders:
   - .bmad/ folder with configuration
   - .github/agents/ folder with BMAD agents
   - .vscode/settings.json updates

Expected Output:
- Multiple agents installed in .github/agents/
- VS Code settings configured for GitHub Copilot
- Confirmation message: "✓ GitHub Copilot configured"

Troubleshooting:
- If npm errors: Ensure Node.js 18+ is installed
- If permission errors: Try with sudo (macOS/Linux)

TASK 3: UNDERSTAND THE USER STORY

User Story:

"As a user of the Real World App, I want to see a transaction insights 
dashboard that shows spending patterns over time, so that I can understand

The dashboard should include:
- Monthly spending breakdown by category
- Week-over-week spending comparison chart

TASK 4: INITIALIZE BMAD WORKFLOW

Goal: Set up BMAD tracking for your project and determine the right workflow track.

Context: BMAD adapts to project complexity with three tracks:
- Quick Flow: Bug fixes, small features (< 15 stories typically)
- BMad Method: Products, platforms, complex features (10-50+ stories)
- Enterprise Method: Compliance, scale, governance (30+ stories)

Action:
1. Activate the Analyst agent in Copilot Chat
2. Run workflow initialization:

Prompt (select agent, then type):
```
*workflow-init
```

Or say naturally:
```
Run workflow-init - I want to build a transaction insights dashboard 
for an existing React/Express application. This is a new feature that 
adds spending analytics with charts, filters, and real-time updates.
```

3. Answer the agent's questions about:
   - Project goals and scope
   - Whether this is new code or existing codebase
   - Estimated complexity

Expected Output:
- Agent recommends a track (likely BMad Method for this feature)
- File created: docs/bmm-workflow-status.yaml
- Clear next steps provided

Questions:
- Why did the agent recommend this track?
- What happens if you want to change tracks later?
- How does workflow-status.yaml help track progress?

3. Create tech-spec instead of full PRD:

Prompt:
```
*tech-spec

Fix a bug where transaction list doesn't update after creating new transaction.
The issue is in the React state not refreshing after POST to /transactions.
Solution should trigger re-fetch or use optimistic updates.
```

4. Implement directly with DEV agent

Quick Flow is 3 steps: tech-spec → dev → optional review

WORKFLOW SUMMARY

Complete BMAD Method Workflow:

Phase 1 - Analysis (Optional):
- workflow-init → Set up tracking
- brainstorm-project → Explore ideas
- product-brief → Clarify vision

Phase 2 - Planning (Required):
- prd → Create requirements (or tech-spec for Quick Flow)
- ux → Design user experience (if UI involved)

Phase 3 - Solutioning (Required for BMad Method/Enterprise):
- create-architecture → Design system
- create-epics-and-stories → Break down work
- implementation-readiness → Validate plans

Phase 4 - Implementation (Required):
- sprint-planning → Set up tracking
- create-story → Draft next story
- dev-story → Implement code
- code-review → Quality check
- retrospective → Epic completion review

---

KEY LEARNINGS

1. Fresh Chats for Each Workflow
   - Prevents context pollution and hallucinations
   - Maximum context capacity for complex work

2. Specialized Agents = Better Results
   - Each agent has deep domain expertise
   - Let PM do requirements, Architect do design, etc.

3. Track Matters
   - Quick Flow for small tasks
   - BMad Method for features/products
   - Enterprise for compliance/scale

4. Tracking is Automatic
   - workflow-status.yaml and sprint-status.yaml
   - Agents update these as you work

5. Flexible Command Input
   - Use shorthand: *prd
   - Use menu numbers
   - Use natural language: "Let's create a PRD"

"Agent not showing workflows"
→ Ensure you selected the right BMAD agent
→ Wait for agent menu to appear after selection
→ Re-install with: npx bmad-method@alpha install

"Hallucinations in responses"
→ Always use FRESH chats for each workflow
→ Don't chain multiple workflows in one chat

→ Re-run workflow-init if corrupted

COMPARISON: BMAD vs SPEC KIT

| Aspect           | BMAD Method               | Spec Kit                    |
|------------------|---------------------------|-----------------------------|
| Approach         | Agile with AI agents      | Specification-first         |
| Agents           | 19 specialized personas   | Single AI assistant         |
| Workflow         | Phase-based (4 phases)    | Command-based (/speckit.*)  |
| Best For         | Team-style development    | Solo/focused development    |
| Tracking         | YAML status files         | Git branches + spec folders |
| Installation     | npx bmad-method@alpha     | uvx specify                 |

Choose BMAD when:
- You want AI "team members" with specific roles
- Following agile/scrum methodology
- Complex projects with multiple concerns

Choose Spec Kit when:
- You prefer specification-first approach
- Simpler workflow with clear phases
- Focused single-feature development

Both can be effective - choose based on your preferred working style!
